# [정산팀] 배치 청구액이 정산 예상액과 맞지 않습니다

## 증상

- 오늘 배치(주문 12건)를 돌리면 청구액이 정산 예상액과 다른 주문이 여러 건 나옵니다.
- 돌릴 때마다 틀리는 주문이 달라집니다. 어제 틀렸던 주문이 오늘은 맞기도 합니다.
- 틀린 주문은 모두 고객에게 **더 많이** 청구되었습니다.

## 재현

```bash
python -m shop          # 주문별 청구액과 예상액 비교 출력
python -m pytest        # test_batch_totals 실패
```

## 최근 변경 사항 (이번 배포에 포함)

1. 단가 조회에 TTL 캐시 도입 (`shop/catalog.py`)
2. 배치 처리 병렬화, 워커 4개 (`shop/orders.py`)
3. 할인 금액 반올림 정책 변경 (`shop/pricing.py`)
4. 쿠폰 중복 적용 방지 로직 리팩터링 (`shop/coupons.py`)
5. 재고 차감 후 창고 시스템 연동 추가 (`shop/inventory.py`)
